# Task A5 – Transactions and SQL Injection

## Objective
Study JDBC transactions and SQL injection prevention.

## Files
- WalletTransfer.java – Demonstrates transaction-based wallet transfer.
- LoginSecurity.java – Demonstrates safe login using PreparedStatement.
- sample_wallets.txt – Sample wallet data.
- TransactionAnalysis.md – Transaction and security analysis.

## Result
Designed a JDBC wallet transfer using commit and rollback and implemented parameterized login queries using PreparedStatement.

## Note
The Java classes require a database Connection supplied by a JDBC application. Database execution is covered in the implementation tasks.
