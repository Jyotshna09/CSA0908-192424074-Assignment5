# Task 4 – Java Serialization

## Objective
Demonstrate object serialization and deserialization using
Hostel, Room and Resident classes.

## Technologies
- Java Serializable
- ObjectOutputStream
- ObjectInputStream
- transient
- serialVersionUID

## Execution

From the main repository folder:

javac Task04_Serialization/src/*.java

java -cp Task04_Serialization/src SerializationDemo

## Output
The program saves hostel information to hostel.dat and
loads the serialized object back.

## Result
Successfully demonstrated object graph serialization,
deserialization and transient fields.
